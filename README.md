# Court Click Frontend Machine Test

## Overview

This project is a responsive Order Management Dashboard developed as part of the Court Click Frontend Machine Test.

## Tech Stack

* Next.js (App Router)
* TypeScript
* Ant Design
* React

## Features

* Responsive dashboard layout
* Orders table
* Order details drawer
* Filter users modal
* Create tag modal
* Assign clerk modal
* Add clerk modal
* Share order modal
* Form validation
* Reusable React components
* TypeScript support

## Installation

Clone the repository:

```bash
git clone https://github.com/Fidhil10/court-click-frontend.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```

## Build for Production

```bash
npm run build
npm start
```
